**Date:** 2026-02-24
**Reference:** [mjeblick/dabstab_skill_creation solver.py](https://gitlab-master.nvidia.com/mjeblick/dabstab_skill_creation/-/blob/max/skills_discovery_eval/dabstab_solver/solver.py)

## Goal

Port the DABstab solver agent into the agent006 framework with native 006 conventions.
The agent's *operation* should match the original as closely as possible; the *implementation*
should be idiomatic 006 (Agent subclasses, CodeActStrategy, Pydantic models, inline docstrings).

## Modes of Operation

| Mode | Input | Phases | Output |
|------|-------|--------|--------|
| `bootstrap` | question + ground-truth answer + guidelines | Discovery → Solve → Verify/Reflect × N → Extract | answer + correct flag + new_functions + new_example + solution_script |
| `discover` | question + guidelines (no GT) | Discovery → Solve → Extract | answer + new_functions + new_example |
| `benchmark` | question (plain string or JSON) | load skills → Discovery → Solve | `"FINAL ANSWER: {answer}"` |

Bootstrap and discover accumulate skills into `skills/zero_shot_examples.py`.
Benchmark reads from that file and uses it to guide solving.

---

## Agent Architecture

Two top-level orchestrators, sharing lower-level sub-agents:

```
BootstrapOrchestrator (Agent)          ← bootstrap + discover modes
  ├── DiscoveryAgent                   Phase 1
  ├── SolverAgent                      Phase 2
  ├── SolutionVerifier                 Phase 3 (bootstrap only)
  └── SkillExtractor                   Phase 4

BenchmarkSolver (Agent)                ← benchmark mode
  ├── DiscoveryAgent                   Phase 1
  └── SolverAgent                      Phase 2 (with skills pre-loaded)

SkillLibrary (plain class, not Agent)  ← I/O for zero_shot_examples.py
```

`run_solver.py` instantiates the right top-level agent based on `--mode`.

### Output Models

```python
class PythonSource(BaseModel):   # already exists in dabstep_agent008.py
    code: str
    @field_validator("code")

    helper_functions: str        # Python source with reusable defs

    example_rule: str
    example_code: str

class ComputedAnswer(BaseModel):

    accepted: bool

    answer: str
    correct: bool | None         # bootstrap only
    new_functions: str
    new_example: str
    solution_script: str
    reflections: list[str]
    attempts: int
```

## Sub-Agent Specifications

### DiscoveryAgent

- Strategy: `CodeActStrategy`
- Has: `self.data` (DataContext), `self.question` (str)
- Does:
  - Ask LLM for 3 key terms from the question
  - `grep_manual` each term (search `manual.md`)
  - Explore CSV/JSON schemas (bootstrap/discover: deep; benchmark: light)
- Returns: `discovery_context: str` — injected into SolverAgent system prompt

### SolverAgent

- Strategy: `CodeActStrategy`
- Has: `self.data`, `self.discovery_context`, `self.worked_examples`, `self.helper_functions`
- Returns: `ComputedAnswer`

### SolutionVerifier (bootstrap only)

- Strategy: `CodeActStrategy`
- Has: `self.data`, `self.relevant_rules`, `self.gt_answer`
- Returns: `VerificationResult(accepted, reflection)`
- On failure: reflection becomes `hint` for next `SolverAgent` call

### SkillExtractor (bootstrap/discover)

- Strategy: `CodeActStrategy` with structured output
- Has: `self.data`, `self.solve_messages_summary`
- Makes two LLM calls:
  1. Structured extraction → `ExtractionResult` fields (functions, example_*)
  2. Script extraction → `ExtractionResult.solution_script: PythonSource`
- Returns: `ExtractionResult`

## I/O Interface

**Input** (consistent with evaluation harness):
- `benchmark`: plain string or `{"question": "..."}`
- `bootstrap`/`discover`: `{"question": "...", "answer": "...", "guidelines": "...", "existing_functions": "...", "existing_examples": "..."}`

**Output**:
- `benchmark`: `"FINAL ANSWER: {answer}"`
- `bootstrap`/`discover`: `"FINAL ANSWER: {answer}\n\n__STRUCTURED_OUTPUT__\n{json}"`

## Key Implementation Notes

- `PythonSource` is already defined in `dabstep_agent008.py` — reuse/import
- `DataContext` is already defined in `dabstep_agent008.py` — reuse/import
- Fee matching helper functions (`applies_to_all`, `volume_matches`, etc.) from agent008 — reuse
- Bootstrap retry loop: max_retries configurable (default 3), same as original
- Discovery term count: configurable (default 3 key terms), same as original

## Testing Plan

1. **Smoke test** (`run_solver.py --mode benchmark`): single question, empty skill library → `"FINAL ANSWER: ..."` output
2. **Bootstrap test**: 5 labeled questions → `zero_shot_examples.py` is created with helper functions + examples
3. **End-to-end**: benchmark run after bootstrap → verify examples appear in SolverAgent prompt
4. **Eval harness**: add `dabstep_agent009.py` wrapper in `experiments/evaluation-ablations/agents/` for scoring
